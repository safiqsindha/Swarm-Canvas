Reply with one JSON object and nothing else.
paints is a list of up to 8 objects. Each object has column, row, and color.
column is one letter from A to X. row is an integer from 1 to 16. Do not join them into one string.
Each color must be one you already hold, or a catalog color already granted to you.
requests is a list of catalog color codes.
scratchpad is a short note you keep for the next round. Use it when a plan should survive the turn.
A name is at most 20 characters and is only kept on the first round.
Omit any key you are not using.
